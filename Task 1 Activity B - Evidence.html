Assignment A — Northgate Health Trust (Security-framed)

Task 1 Activity B — Security Requirements 18 marks
Scenario: UK health trust, satellite clinic, patient-adjacent data, 20 users, clinical admin & finance departments, shared building, VLAN separation, WPA2 Wi-Fi.
Requirement: Translate each risk from Activity A into a control — password policy, account lockout, GPO choices, RBAC permission matrix, WPA2/WPA3, backup-as-mitigation. Cover hardware, software, server configuration, and IPv4 scheme with two VLANs.
Top-band model answer (Band 4 — 15–18 marks): The requirements document below is structured exactly to the Pearson Distinction-level template, translating every risk from Activity A into a specific control.

Hardware required (including network devices, end user computers and a server)

DeviceDescription/PurposeConnection details
1 x Onsite Server Acts as the central storage for patient-adjacent records and sensitive financial data. Includes RAID 1 configuration to ensure redundancy and prevent data loss, and full-disk encryption to protect sensitive information (GDPR compliance). Connected to the managed switch using UTP Cat6a for stable gigabit-speed connections. Redundant power provided via a UPS. Placed in a secure, lockable cabinet on the occupied floor to reduce physical access risks.
20 x Desktop Computers Provide dedicated workstations for Clinical Admin (10) and Finance (10) staff. Sufficient processing power (multi-core CPUs), 16GB RAM, and encrypted SSD storage for speed and security. Supports EDR and BitLocker. Each desktop connected to the managed switch via UTP Cat6a for high-speed, reliable connectivity. Wired connections reduce exposure to Wi-Fi threats. Organised so Clinical Admin and Finance are logically separated via VLANs.
1 x Network Router Provides internet connectivity, firewall protection, VLAN support, and traffic monitoring. Isolates internal networks from external threats, enforces secure remote access for staff, and prioritises critical traffic. Connected via UTP Cat6a to the ISP modem and managed switch. VLANs separate Clinical Admin, Finance, and guest networks to prevent unauthorised access. Logs network activity for monitoring and auditing.
1 x Managed Network Switch Connects all wired devices. Supports VLANs to segment traffic between Clinical Admin, Finance, and Wi-Fi, and enables port security to prevent rogue devices from connecting (mitigates VLAN hopping). Connected via UTP Cat6a to all devices. VLAN configuration ensures departmental traffic remains isolated. Port security disables unused ports or requires MAC authentication.
2 x Wireless Access Point Provides secure Wi-Fi coverage for the clinic, supporting staff mobility. Uses WPA2-Enterprise (or WPA3) encryption, separate SSIDs for staff and guests, and allows seamless roaming. Connected to the managed switch via UTP Cat6a. Access control lists restrict devices to authorised users. Guest SSID traffic is isolated from internal network VLANs.
4 x Uninterruptible Power Supply (UPS) Protects critical hardware (server, switch, router) from power surges or outages and allows safe shutdown during prolonged outages, preventing data corruption. Critical clinical and finance PCs should also be connected to a UPS. UPS units positioned close to connected hardware and regularly tested.
1 x Network Printer Shared network device for both departments, with user authentication to control access to sensitive documents and restrict guest printing. Connected via wired network to the switch. Guest printing routed through a separate VLAN to isolate from internal systems. Logs print activity for auditing.
1 x Server Cabinet Houses the server, switch, router, and UPS, providing physical security, airflow, and cable management. Lockable doors restrict access to authorised personnel. All devices connected with structured Cat6a cabling. Cabinet placement minimises risk from environmental hazards and restricts physical access by other tenants.

Type of configurationDescription/Purpose/Configuration details
AD-DSManages authentication and authorisation for all 20 staff members. Enforces departmental access controls. Configuration: top-level domain northgate.local, server name NHT-Server1. Departments represented as Organisational Units (OUs) for granular control.

Shared FoldersThree main folders created on the server: a Company-wide folder (Read/Write for all), a Clinical Admin-only folder, and a Finance-only folder. Organises data storage, maintains departmental separation, and protects sensitive data from accidental access.
File/Folder Permissions (RBAC)Permissions set so Clinical Admin staff cannot access Finance folders and vice versa, while both can read/write to the Company folder. Protects sensitive data from unauthorised access, especially given the shared building environment. Domain Admins retain Full Control.
Anti-Virus SoftwareInstalled on the server and all desktops. Scheduled weekly full system scans performed, with daily quick scans. Automatic updates ensure virus definitions remain current, reducing the risk of infection from external sources or removable media.
Password PoliciesStrong password enforcement: minimum 12 characters, complexity required (uppercase, lowercase, numbers, symbols), and mandatory changes every 90 days. Password history of 10 prevents reuse. Reduces risk of unauthorised access.
Account Lockout PoliciesThreshold of 5 invalid attempts, lockout duration of 30 minutes, and reset counter after 30 minutes. Slows down brute-force attacks without permanently blocking legitimate users.
Group Policy Objects (GPOs)Five distinct GPOs applied: Password Policy (complexity/length), Account Lockout (threshold/duration), Screen Lock (5 min inactivity), USB Restriction (deny write for non-admins), and Audit Policy (logon and file access events).
Software FirewallProvides additional protection by filtering inbound and outbound traffic on the server. Helps secure departmental VLANs and prevents unauthorised access attempts from external networks or neighbouring offices.
Windows UpdatesEnsures the server and all desktops remain protected against known software vulnerabilities. Automatic updates enabled, and critical security patches deployed within 24 hours of release.
Wireless ConfigurationWPA2-Enterprise (or WPA3 where supported) with RADIUS authentication. Strong PSK if WPA2-Personal is used (≥20 characters). Guest network isolated on a separate VLAN.
Regular BackupsDaily incremental backups at 02:00 and weekly full backups on Sunday at 02:00. Backups stored on an encrypted external drive (offline when not in use) with optional off-site copy. Retention: 4 weekly fulls, 30 daily incrementals. Monthly restore tests documented in the test log.
