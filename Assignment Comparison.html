Task 1 Brief

You work for a service provider which has been contracted to set up the IT infrastructure for a UK health trust, Northgate Health Trust, which is opening a satellite clinic. The clinic handles patient-adjacent data, so the design must be driven by a security risk assessment.

The clinic will need to provide computing facilities for 20 people, working in two main departments: clinical administration and finance/billing.

The clinical administration department stores patient-adjacent records (names, addresses, appointment data). The finance department stores sensitive financial data. Both are subject to UK GDPR and the Data Protection Act 2018, and the trust is expected to align with NCSC Cyber Essentials.

A fileserver will be needed with:

  • a common shared area for all users
  • a shared area for clinical administration users only
  • a shared area for finance users only

The building is a shared building; Northgate Health Trust will occupy one floor, with other tenants on other floors.

All users require wired connections to desktop computers. Clinical administration and finance users must be on separate VLANs. A secure Wi-Fi network is required (WPA2 minimum; WPA3 preferred where supported).

Activities

Quality of Communication 6 marks

When producing evidence in these activities, you should use high-quality communication that:

  • includes common vocabulary that will be understood within the digital industry
  • is suitable for the target audience
  • ensures the different elements of your design are clear, allowing a third party to easily interpret them.

Activity A — Risk Assessment 18 marks (Suggested Time: 5 Hours)

Complete a risk assessment using the file Task1_DI_NHT_RiskAssessment.doc.

You should ensure your risk assessment includes a range of risks, explicitly biased toward security control types and the risk management process.

For each risk, your risk assessment must cover:

  • the threat that could cause harm
  • the likelihood of the threat occurring
  • the vulnerabilities or weaknesses in the security
  • the asset that needs to be protected
  • the possible impact or damage if the threat occurs
  • the control type(s) applied — preventative, detective, corrective, deterrent, directive, or compensating
  • the risk response — accept, avoid, mitigate, or transfer
  • the risk management process stage — identify → probability → impact → prioritise → mitigate

Your risk assessment must cite GDPR/DPA 2018 and NCSC Cyber Essentials where relevant.

Activity B — Security Requirements 18 marks (Suggested Time: 5 Hours)

Complete the infrastructure requirements template using the file Task1_DI_NHT_Requirements.docx.

You should ensure your requirements protect against the risks you identified in Activity A. Each risk must translate into a control.

This should cover:

  • hardware required, including network devices, end-user computers and a server
  • software required
  • server configuration and settings to provide the required functionality
  • IPv4 addressing scheme, providing for two VLANs for clinical administration and finance users
  • password policy and account lockout settings
  • GPO choices that enforce security
  • folder permission matrix using Role-Based Access Control (RBAC)
  • WPA2/WPA3 configuration for the wireless network
  • backup configured as a risk mitigation control

Activity C — Cisco Packet Tracer Simulation 9 marks (Optional, Suggested Time: 5 Hours)

Simulate the network using Cisco Packet Tracer.

Your network should include:

  • all network devices
  • all end-user computers
  • the requirements in the Task 1 Brief section

Meet these requirements:

  • use VLANs to separate clinical administration and finance departments
  • use wireless security by configuring WPA2

Total for Task 1 = 51 marks (45 task marks + 6 quality of communication)

Task 2 Brief

Northgate Health Trust has asked you to implement a version of the network for their new satellite clinic to be used for testing.

The test network needs to include:

  • at least two workstations running desktop operating systems
  • one computer to be used as a server running a server operating system

Install and configure the software and set up the domain 9 marks (Suggested Time: 6 Hours)

Install and configure the operating systems. The computers can be physical or virtual.

The server needs to be set up as a domain controller running:

  • Active Directory Domain Services and DNS
  • DHCP to provide workstations with IP addresses

Apply appropriate security settings, such as password policy and account lockout, to the server (or confirm they are active) and confirm the security settings or features are active.

Set up user accounts, shared folders and permissions 9 marks (Suggested Time: 6 Hours)

The domain needs at least two user groups: clinical administration and finance. Create at least one domain user for each group.

Shared folders for the whole company and for the clinical administration and finance groups should be created on the server.

Set permissions as shown in the table:

GroupsCompanyClinical AdminFinance
Clinical AdminRead/WriteWriteNone
FinanceRead/WriteNoneWrite

Using the test log template, create a test plan for the permissions and test that permissions are correctly applied to users in the different groups.

Group Policy settings 6 marks (Suggested Time: 4 Hours)

Create and apply five different Group Policy settings for users which will make the domain more secure (e.g. password complexity, screen lock, USB restriction, audit policy, Windows Firewall enforcement).

Using the test log template, test the policies to ensure they have been applied correctly.

Configure a backup schedule 6 marks (Suggested Time: 4 Hours)

Configure a scheduled backup of the shared folders on the server to an external drive or additional virtual drive. Select an appropriate time and frequency.

Test the backup by restoring one of the backups.

You should also create a log that includes suitable annotated screenshots demonstrating the steps you followed.

Total for Task 2 = 30 marks

Task 1 Brief

You work for a service provider contracted to set up the IT infrastructure for Harbourview Media, a media company that has recently suffered a disk failure.

The company wants a test domain built with disaster recovery and continuity as the driving concern.

The student must justify every source used — manufacturer documentation, NCSC guidance, and vendor whitepapers.

The office will provide computing facilities for 20 people, working in two main departments: production and finance.

A fileserver will be needed with a common shared area, a production-only area, and a finance-only area.

The building is shared; Harbourview Media will occupy one floor. All users require wired connections. Production and finance users must be on separate VLANs. A secure Wi-Fi network is required.

Activity A — DRP/BCP-Oriented Risk Assessment 18 marks (5 Hours)

Complete a risk assessment using the file Task1_DI_HM_RiskAssessment.doc.

This risk assessment is framed around Disaster Recovery Planning (DRP) and Business Continuity Planning (BCP). You must:

  • define the scope of the DRP — organisational / departmental / individual
  • state the risk responses — accept / avoid / mitigate / transfer
  • incorporate back-ups and off-site alternative storage
  • calculate and justify RTO, RPO, MTBF, and MTTR
  • address encryption of data at rest and in transit

For each risk, cover: threat, likelihood, vulnerabilities, asset, and impact.

Activity B — Requirements with Source Justification 18 marks (5 Hours)

Complete the infrastructure requirements template using the file Task1_DI_HM_Requirements.docx.

This activity requires a mandatory sources-of-knowledge log. For each design decision (e.g. "hourly incremental backup"), you must:

  • cite at least two sources
  • apply reliability/validity factors — authority, date, version, corroboration
  • flag potential bias — vendor bias vs NCSC neutrality

Your requirements must also include hardware, software, server configuration, IPv4 addressing for two VLANs, the cable-making standard justified against TIA/EIA-568, and the backup type chosen and justified.

Activity C — Backup Schedule and Restore-Test Plan 9 marks (Optional, 5 Hours)

Produce a backup schedule and restore-test plan as the design artefact. Specify frequency and type of backup, source and destination, retention policy, and the restore-test procedure and success criteria.

Total for Task 1 = 51 marks (45 task marks + 6 quality of communication)
